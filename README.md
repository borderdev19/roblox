# Creature Island — Mini Tycoon

Roblox MVP built with **Luau + Rojo**. Source files are editable and versioned in this repository.

## Current gameplay
- A simple island and spawn generated by the server.
- Six collectible creature species producing passive coins every 2 seconds.
- Eight production upgrades and three island progression levels.
- Mobile-friendly purchase interface.
- Server-authoritative prices and purchases; DataStore save/load.
- No paid random rewards or Robux purchases implemented.

## Build
Install [Rojo](https://rojo.space/) 7.5.1 and run:
```sh
rojo build default.project.json --output CreatureIsland.rbxlx
```
GitHub Actions runs this build on each push to `main` and uploads the resulting place as an artifact.

## Status and limitations
**Source MVP, not yet play-tested in Roblox Studio or published.** The CI workflow still needs its first successful run. Roblox DataStore persistence must be verified in a published experience. This project currently has no creature 3D models, plot ownership, paid products, or production monetization.

## Roblox publication
Publishing through Roblox Open Cloud requires a configured universe/place, an API key stored in GitHub Actions secrets, and a separate deployment workflow. No Roblox API key should be committed to this repository.
